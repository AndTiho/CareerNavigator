# Проект CareerNavigator

## Описание
Проект, который будет получать информацию о вакансиях с платформы hh.ru в России,
сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.\
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/CareerNavigator.git
```
2. Установите зависимости:
```
poetry install
```
## Использование
**Здесь будет информация чуть позже**

## Запуск и ожидаемое поведение программы
Для запуска программы воспользуйтесь:
```
python main.py
```
Программа находится на стадии разработки.

## Тестирование:
Наш проект покрыт юнит-тестами Pytest. Для их запуска выполните команду:

`pytest`

## Документация:
Для получения дополнительной информации, вы можете воспользоваться возможностью
чтения файла [.toml](pyproject.toml)

В данный момент проект распространяется без лицензии.
